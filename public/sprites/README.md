# Спрайты

Кидаешь сюда PNG с правильным именем — он появляется в игре вместо кружка. Ничего
регистрировать в коде не нужно.

Чего нет — рисуется как раньше. Можно добавлять по одному, игра не сломается ни на одном,
ни на половине, ни на всех.

---

## Требования к файлу

| | |
|---|---|
| Формат | PNG, **прозрачный фон** (без него будет чёрный прямоугольник) |
| Размер | **256×256** для рядовых, **512×512** для боссов. Больше не нужно — в игре они по 40–90 px |
| Ракурс | **Вид спереди**, персонаж стоит лицом к зрителю |
| Поза | Нейтральная стойка, руки видны, ноги на нижней границе |
| Направление | Рисовать смотрящим **вправо или прямо**. Влево игра отражает сама |
| Поля | Персонаж занимает почти всю высоту, по краям 5–10 px пустоты |

**Про ракурс отдельно.** Камера в игре сверху, но спрайты нужны фронтальные — так делают
Vampire Survivors и Brotato. Вид строго сверху (макушка и плечи) читается как клякса и
требует по картинке на каждое направление. Фронтальный ракурс — одна картинка на юнита.

**Якорь — ноги.** Спрайт ставится так, чтобы низ картинки был на земле. Поэтому персонаж
должен стоять на нижней границе кадра, а не висеть по центру.

## Что писать нейросети

Общий хвост промпта, одинаковый для всех — он и даёт единый стиль:

```
front view, full body, standing, neutral pose, feet at bottom edge,
transparent background, centered, anime style, dark gritty horror tone,
desaturated rust and ash palette, low detail, readable silhouette,
game sprite, no text, no watermark, no shadow on ground
```

Дальше подставляешь описание конкретного юнита. Например:

```
young girl with pink hair, two short bone horns on head, red eyes,
torn hospital gown, barefoot, blank expression
<общий хвост>
```

```
riot police officer in black tactical armor, full face helmet,
large transparent ballistic shield held forward
<общий хвост>
```

Три вещи, на которых чаще всего спотыкаются:

1. **Силуэт важнее деталей.** В игре юнит 40–90 px. Мелкая проработка лица не видна
   вообще, а вот узнаётся ли фигура по контуру — видно сразу. Если сомневаешься, проси
   меньше деталей и контрастнее силуэт.
2. **Проси прозрачный фон явно** и всё равно проверяй. Многие модели рисуют белый или
   клетчатый фон вместо альфа-канала — тогда фон надо снести вручную.
3. **Единая палитра важнее качества отдельной картинки.** Десять спрайтов в одной гамме
   выглядят как игра, три шедевра в разных стилях — как свалка. Держи общий хвост промпта
   неизменным.

## Проверить, чего не хватает

В консоли браузера во время игры:

```js
window.__missingSprites?.()
```

Вернёт список запрошенных имён, для которых файла не нашлось.
